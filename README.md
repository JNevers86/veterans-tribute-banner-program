# Veterans Tribute Banner Program

Standalone Phase 1 prototype for an organization-led Hometown Heroes / Veterans Tribute Banner intake site.

## Local

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3010`.

## Render Staging

Create a new Render Web Service from this project.

- Runtime: Node
- Build command: `npm install && npm run build`
- Start command: `npm start`
- Root directory: project root, unless deployed inside a larger repository

This Phase 1 prototype uses local/mock state only. It does not save submissions, upload photos, accept payments, or send emails yet.
